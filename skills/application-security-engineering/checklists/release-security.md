# Release Security Checklist

- [ ] Security-critical changes identified
- [ ] Required security tests pass
- [ ] No unresolved critical/high confirmed findings without explicit risk acceptance
- [ ] New dependencies reviewed
- [ ] Secret scanning/security baseline run as required
- [ ] Security configuration documented
- [ ] Database/security migration failure mode understood
- [ ] Privileged feature flags/config fail safely
- [ ] Security logging/alerts updated where needed
- [ ] Rollback does not reintroduce known vulnerability
- [ ] Security regression tests are in CI
