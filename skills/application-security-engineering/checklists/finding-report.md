# Finding Report Checklist

- [ ] Specific title
- [ ] Affected version/component
- [ ] Preconditions
- [ ] Violated security property
- [ ] Reproduction/evidence
- [ ] Expected vs actual
- [ ] Demonstrated impact only
- [ ] Root cause
- [ ] CWE mapping when clear
- [ ] ASVS/OWASP mapping when useful
- [ ] Severity rationale / CVSS vector if used
- [ ] Concrete remediation
- [ ] Regression test recommendation
- [ ] Verification after fix
- [ ] Sensitive evidence redacted
