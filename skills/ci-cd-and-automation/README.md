# Zelyq CI/CD and Automation Skill

This skill upgrades CI/CD from a list of workflow commands into a release-engineering discipline.

It is intentionally:
- platform-aware but not Node-specific;
- risk-adaptive rather than "all gates always";
- security-conscious about untrusted workflow code;
- artifact-centric: build once, promote by digest;
- progressive-delivery aware;
- database/configuration aware;
- designed for human and AI feedback loops.

`SKILL.md` contains routing and operating procedure. `references/` contains deep knowledge, `profiles/` adapts by repository type, `recipes/` contains repeatable patterns, `scripts/` assists audits, and `evals/` tests judgment.
