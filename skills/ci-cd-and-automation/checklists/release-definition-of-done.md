# Release Definition of Done

- [ ] Release source revision is known.
- [ ] Release artifact has immutable version/digest.
- [ ] The same verified artifact is promoted between environments where applicable.
- [ ] Provenance/SBOM/signing requirements are satisfied.
- [ ] Database/config compatibility is understood.
- [ ] Rollout strategy matches blast radius.
- [ ] Promotion and rollback criteria are defined for staged releases.
- [ ] Production deployment concurrency is controlled.
- [ ] Release health is observable.
- [ ] Rollback or roll-forward recovery path is known.
- [ ] Previous known-good artifact/config is available.
- [ ] Release record includes commit/artifact/environment/time.
- [ ] Post-deploy verification ran successfully.
