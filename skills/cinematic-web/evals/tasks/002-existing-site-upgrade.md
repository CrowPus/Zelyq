# Eval 002 — Existing Site Upgrade

## Prompt
Upgrade the hero and first two sections of an existing semantic marketing page to feel cinematic without changing its message, navigation, forms, SEO-critical content, or design-system tokens.

## Expected
Inspect first; avoid rewriting the app; choose DOM-only motion if 3D adds no value; preserve semantics; visually test.

## Major failure
Adding Three.js merely because the skill is active.
