# R3F + GSAP Template Overlay

Use this as an architectural starting point, not a frozen application scaffold.

Host dependencies:

```bash
npm install three @react-three/fiber @react-three/drei gsap
```

Included:
- `CinematicCanvas.jsx` — persistent fixed canvas;
- `ProductScene.jsx` — 3D subject exposed through a ref;
- `useCinematicTimeline.js` — scoped GSAP/ScrollTrigger lifecycle;
- `page-example.jsx` — semantic DOM + cinematic section.

Adapt imports and framework conventions to the host repository.
