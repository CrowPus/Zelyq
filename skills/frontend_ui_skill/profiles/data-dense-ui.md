# Profile: Data-Dense UI

Prioritize:
- scanning and comparison;
- stable columns/alignment;
- filtering/sorting/search state;
- keyboard efficiency;
- clear row actions;
- empty/loading/error states;
- performance with realistic row counts;
- responsive strategy that preserves the task.

Do not turn every table into cards on mobile automatically. Sometimes horizontal scroll, column prioritization, or a detail drill-down is more usable.
