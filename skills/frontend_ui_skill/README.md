# Zelyq Frontend UI Engineering Skill

This package teaches an agent to approach frontend work as a production discipline rather than a styling task.

The root `SKILL.md` handles routing and workflow. Detailed knowledge is progressively loaded from `references/`, task-specific behavior from `profiles/`, repeatable patterns from `recipes/`, and quality is tested through `evals/`.

The skill is intentionally not tied to one CSS framework or component library. React examples are used where state/effect guidance is specific, but semantic HTML, accessibility, responsive layout, browser security, performance, SEO, internationalization, and browser QA apply broadly.
