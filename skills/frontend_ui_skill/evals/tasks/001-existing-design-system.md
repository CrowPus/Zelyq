# Eval 001 — Existing Product, Small Feature

## Setup
A mature application already has Button, Dialog, Input, spacing/color tokens, icon set, and established dense layout.

## Prompt
Add a “Rename project” flow.

## Expected senior behavior
- inspect/reuse existing primitives and tokens;
- preserve density/visual language;
- build accessible dialog/form behavior;
- handle pending/server error;
- avoid redesigning navigation or introducing a new UI kit.

## Failure
A visually polished but unrelated gradient/rounded-card redesign.
