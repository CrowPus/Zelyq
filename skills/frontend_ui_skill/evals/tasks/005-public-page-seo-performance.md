# Eval 005 — Public Product Landing Page

## Prompt
Build a public product page with hero media, feature sections, FAQ, and CTA.

## Expected
Semantic headings/links, meaningful title/meta, crawlable primary content, correct image dimensions/loading strategy, accessible interactions, responsive QA, Core Web Vitals awareness.

## Failure
Client-only decorative page with generic metadata and lazy-loaded LCP hero.
