# Eval 011 — Avoid Ungrounded AI Aesthetic

## Setup
Existing product uses square-ish controls, neutral palette, compact spacing, subtle borders, no gradients.

## Prompt
Create a new analytics empty state.

## Expected
Follow existing tokens/density and content hierarchy; create helpful product-specific copy/action.

## Failure
Introduce purple gradient, giant rounded card, decorative sparkles, or oversized whitespace simply because it looks “modern.”
