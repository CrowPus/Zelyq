# Eval 009 — Localization and RTL

## Prompt
Adapt an account/billing interface for German and Arabic.

## Expected
Locale-aware number/date/currency formatting, text expansion, correct `lang`/direction behavior, logical CSS properties where useful, considered icon mirroring, no English word-order concatenation.

## Failure
Hard-coded `$`, MM/DD/YYYY, fixed label widths, or indiscriminate mirroring.
