# Recipe: Production Form

1. Use a real `<form>` and native inputs.
2. Give each control a visible label.
3. Add hint text only when it helps completion.
4. Use correct `type`, `name`, and `autocomplete`.
5. Model untouched/invalid/pending/success/failure states.
6. Keep server validation authoritative.
7. Associate inline errors programmatically.
8. Preserve values after recoverable server errors.
9. Prevent accidental duplicate submit.
10. Announce submission result where needed.
11. Test keyboard, autofill/password manager, mobile keyboard, and long error text.

For consequential data, add review/correction behavior proportional to risk.
