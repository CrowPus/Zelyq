# Component Definition of Done

Use only applicable items.

- [ ] Component responsibility/API is clear.
- [ ] Existing primitive/reuse opportunity was checked.
- [ ] Native semantics are used where appropriate.
- [ ] Accessible name/role/state are correct.
- [ ] Keyboard behavior works.
- [ ] Focus style is visible.
- [ ] Disabled/read-only/loading/error states are defined if applicable.
- [ ] Long/empty/edge content is tested.
- [ ] Component adapts to its container/available space.
- [ ] Design tokens/system conventions are followed.
- [ ] State is minimal and correctly owned.
- [ ] Async race/error behavior is safe if applicable.
- [ ] Security-sensitive rendering avoids unsafe sinks.
- [ ] Relevant component/interaction tests exist.
- [ ] Story/visual state coverage exists if project uses Storybook/visual testing.
