# Public Page Definition of Done

- [ ] Unique meaningful title.
- [ ] One clear primary page heading appropriate to content.
- [ ] Semantic sections/navigation/links.
- [ ] Useful meta description where applicable.
- [ ] Canonical/robots strategy is intentional.
- [ ] Primary content is crawlable in the chosen rendering architecture.
- [ ] Images have meaningful alt text when informative and empty alt when purely decorative.
- [ ] LCP resource is intentionally loaded/prioritized.
- [ ] Media dimensions/aspect ratio are reserved.
- [ ] No avoidable CLS from fonts/banners/async content.
- [ ] Structured data, if present, matches visible content.
- [ ] Accessibility and responsive QA completed.
