# Form Definition of Done

- [ ] Real `<form>` semantics used where applicable.
- [ ] Visible labels exist.
- [ ] Input types/names/autocomplete tokens are correct.
- [ ] Instructions are associated with controls.
- [ ] Required/optional meaning is clear.
- [ ] Server validation remains authoritative.
- [ ] Errors are specific and associated programmatically.
- [ ] User input survives recoverable failure.
- [ ] Pending state prevents accidental duplicate submit.
- [ ] Success/failure feedback is perceivable.
- [ ] Keyboard submission and focus behavior work.
- [ ] Password manager/autofill behavior is not intentionally broken.
- [ ] Consequential actions have suitable review/correction safeguards.
