# Page Definition of Done

- [ ] Primary user goal and action are clear.
- [ ] Heading/landmark/document structure is meaningful.
- [ ] Loading, populated, empty, error, permission, and disabled states are handled where applicable.
- [ ] Keyboard-only flow works.
- [ ] Focus is visible and not hidden by sticky/fixed UI.
- [ ] WCAG 2.2 AA concerns were reviewed.
- [ ] Narrow mobile and desktop were visually inspected.
- [ ] Long/realistic content does not break layout.
- [ ] Zoom/reflow does not create avoidable horizontal overflow.
- [ ] Motion respects reduced-motion preference where applicable.
- [ ] Browser console has no unexplained errors.
- [ ] Core interactions remain responsive.
- [ ] Media/async content does not cause avoidable CLS.
- [ ] Public page has correct title/metadata/crawlable semantics if applicable.
- [ ] Locale/RTL concerns were checked if product is localized.
- [ ] Browser QA was performed when tooling was available.
