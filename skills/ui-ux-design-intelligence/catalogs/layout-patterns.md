# Layout Patterns

| Pattern | Use When | Watch Out |
|---|---|---|
| Single column | Reading, forms, focused tasks | Excessive width/empty space |
| Split hero | Message + product visual both matter | Mobile stacking/order |
| Sidebar + content | Stable app navigation | Narrow screens, deep nesting |
| Master-detail | Lists + selected object | Mobile becomes navigation stack |
| Dashboard grid | Multiple independent signals | Equal-card syndrome |
| Table-first | Comparison, dense records | Responsive overflow/actions |
| Canvas + inspector | Creative/dev tools | Keyboard/focus and small screens |
| Command/search-first | Expert retrieval/action | Discoverability for novices |
| Feed | Time/relevance ordered content | Endless scroll/context loss |
| Wizard/step flow | True sequential dependencies | Artificial steps, lost context |
| Bento/modular | Heterogeneous promotional content | Weak scanning hierarchy if every tile is unique |
