# Interaction Pattern Vocabulary

## Selection
- checkbox: independent multiple selection;
- radio: one of a known set;
- segmented control: small mutually exclusive peer options;
- tabs: switch among peer views;
- dropdown/select: compact choice, not good for every small set.

## Disclosure
- accordion: optional sections;
- details/summary: simple disclosure;
- progressive advanced settings;
- inline expansion.

## Commands
- button;
- split button for primary + closely related alternatives;
- menu for secondary commands;
- command palette for expert breadth, never the only discovery path.

## Navigation
- tabs;
- sidebar;
- breadcrumbs;
- bottom navigation/native tabs;
- search;
- drilldown stack.

## Feedback
- inline status;
- toast for transient noncritical acknowledgement;
- banner for persistent page/system issue;
- modal only for interruption requiring focused decision.

Use pattern semantics, not visual similarity, to select components.
