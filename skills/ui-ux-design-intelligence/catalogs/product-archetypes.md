# Product Archetypes

## SaaS / productivity
Prioritize:
- task clarity;
- repeat efficiency;
- persistent navigation;
- state feedback;
- learnability.

## Developer / infrastructure
Prioritize:
- density;
- code/data legibility;
- status hierarchy;
- keyboard efficiency;
- strong error diagnostics.

## Finance / payments
Prioritize:
- trust;
- clear amounts/status;
- confirmation;
- audit/history;
- conservative error handling.

## Healthcare
Prioritize:
- clarity;
- accessibility;
- seriousness;
- error prevention;
- privacy;
- explicit status.

## E-commerce
Prioritize:
- product findability;
- comparison;
- price/availability clarity;
- checkout confidence;
- recovery.

## Creator / media
Prioritize:
- canvas/content prominence;
- media controls;
- discoverable tools;
- progressive complexity.

## Consumer social
Prioritize:
- quick orientation;
- content-first;
- feedback;
- safety/reporting controls;
- interruption tolerance.

## Education
Prioritize:
- progress;
- comprehension;
- pacing;
- feedback;
- accessible content.

## Marketing / launch
Prioritize:
- positioning;
- proof;
- narrative;
- conversion;
- performance.
