# Style Families

Use these as vocabulary for art direction, not automatic presets.

| Family | Good Fit | Risks / Avoid When |
|---|---|---|
| Editorial minimal | Premium content, portfolios, publishing, quiet SaaS marketing | Can become sparse/slow for operational workflows |
| Utility / product-first | SaaS, productivity, B2B tools, settings | Can feel generic if brand expression is ignored |
| Dense enterprise | Admin, finance, ops, developer tools | Requires excellent hierarchy; avoid tiny targets/illegible text |
| Soft / warm human | Wellness, consumer services, education | Too much softness/radius can weaken precision or seriousness |
| Technical / precision | Developer, security, infrastructure, analytics | Avoid jargon-heavy visual language for novice consumers |
| Luxury restraint | High-end commerce/services, premium hardware | Thin type/low contrast can harm accessibility |
| Expressive geometric | Youth brands, media, creative tools | Decoration can overwhelm content and localization |
| Neo-brutalist | Cultural/creative brands, intentional statement products | High contrast/rawness can reduce trust or content comfort |
| Glass/translucent | Layered media/spatial contexts, limited accent surfaces | Contrast, performance, blur overload, nested glass |
| Skeuomorphic/tactile | Specialized creative tools, playful consumer experiences | Can add visual noise and make state unclear |
| Data editorial | Research, analytics storytelling, reports | Requires careful chart semantics and hierarchy |
| Dark cinematic | Media, creative, product launches | Not automatic for productivity; contrast/glow can become fatiguing |
| Calm institutional | Healthcare, government, finance, compliance | Can feel cold if human reassurance is needed |
| Playful illustrative | Kids/family, consumer onboarding, education | Can undermine high-stakes actions if used everywhere |

## Selection questions

For any family:
- Does it support trust level?
- Does it support content density?
- Does it work with accessibility requirements?
- Does it fit audience expectations?
- Does it survive realistic content?
- Does it scale to all product states?
