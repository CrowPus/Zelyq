# Chart Selection

| Question | Prefer |
|---|---|
| Trend over time | Line |
| Compare categories | Bar |
| Rank items | Sorted bar/table |
| Distribution | Histogram/box plot |
| Relationship | Scatter |
| Part-to-whole | Stacked bar; limited pie/donut only when simple |
| Progress to target | Bullet/progress + numeric context |
| Exact values | Table |
| Geographic | Map only when geography matters |

## Avoid by default
- 3D charts;
- gauges for ordinary KPIs;
- radar charts when simple bars explain better;
- many donut slices;
- dual-axis charts without strong justification.
