# Profile: Mobile / Native

## Prime rule
Follow platform conventions unless the product has a defensible reason not to.

For Apple platforms, consult HIG principles, components, navigation, accessibility and typography.

For Material ecosystems, consult Material 3 components/tokens/adaptive guidance.

## Design for
- touch;
- software keyboard;
- interruptions;
- safe areas;
- orientation;
- dynamic text;
- one-handed use where relevant;
- offline/slow network.

Do not port desktop controls pixel-for-pixel.
