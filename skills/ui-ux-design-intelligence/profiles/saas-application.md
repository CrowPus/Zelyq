# Profile: SaaS Application

## Priorities
- rapid orientation;
- persistent task context;
- efficient repeated work;
- trustworthy system status;
- clear permissions/errors;
- scalable navigation.

## Common structure
- app shell;
- workspace/account context;
- primary nav;
- object lists;
- detail/edit surfaces;
- global search/commands as appropriate.

## Avoid
- marketing-style excessive whitespace in core workflows;
- cards for every field;
- hidden actions that experts repeat constantly;
- generic dashboard metrics with no action path.
