# Profile: Design System

## Goal
Create a reusable product language, not a component zoo.

## Start with inventory
Audit existing:
- primitives;
- tokens;
- variants;
- duplication;
- accessibility;
- usage frequency.

## Define
- principles;
- foundations;
- semantic tokens;
- components;
- patterns;
- content guidance;
- governance.

## Evidence
Promote components into the system because they recur or encode an important standard—not because one page happens to need them.

## Documentation
Every component should include:
- purpose;
- anatomy;
- variants;
- states;
- use/don't use;
- accessibility;
- responsive behavior;
- content constraints.
