# Profile: Data-Dense Dashboard

## Priority
Help users notice, compare, diagnose, and act.

## Hierarchy
1. urgent/abnormal;
2. primary operating metrics;
3. trends/context;
4. drilldown.

## Use
- tables for exact comparison;
- charts for pattern;
- filters with visible scope;
- saved views if repeat use matters;
- dense but legible spacing.

## Avoid
- giant KPI cards consuming the viewport;
- decorative gradients behind numbers;
- charts with no decision attached;
- hidden filter state.
