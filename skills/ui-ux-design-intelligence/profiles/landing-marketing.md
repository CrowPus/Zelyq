# Profile: Landing / Marketing

## Priorities
- positioning;
- audience relevance;
- proof;
- product understanding;
- conversion.

## Start with content
Create message hierarchy before aesthetic sections.

## Visual storytelling
Use visuals to explain product/outcome, not merely decorate.

## Avoid
- invented testimonials/logos/numbers;
- generic hero copy;
- 3 equal feature cards as automatic section;
- high-motion effects that slow comprehension;
- CTA repetition without new context.
