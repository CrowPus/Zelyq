# Profile: Existing Product

## Prime directive
Do not redesign the system unless asked.

Inspect:
- token usage;
- component variants;
- page templates;
- icon family;
- density;
- content tone;
- motion;
- responsive behavior.

## Goal
Make the new feature feel as if the existing team designed it.

Allow improvements when:
- existing behavior is clearly broken;
- accessibility requires change;
- new requirement cannot fit current pattern.

When deviating, explain the reason internally and minimize blast radius.
