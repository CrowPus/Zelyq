# Platform Conventions

## Principle

Products should feel intentional on every platform.

Apple HIG and Material provide platform/system guidance for familiar controls, navigation, layout, accessibility, typography, and motion.

## Native/mobile

Prefer system conventions for:
- navigation;
- back behavior;
- sheets/dialogs;
- text inputs;
- menus;
- switches;
- permissions;
- gestures.

Custom visuals can sit on top of familiar interaction behavior.

## Web

Use native web conventions:
- links navigate;
- buttons act;
- browser back/forward works;
- keyboard focus works;
- URL can represent navigable/shareable state where appropriate.

## Cross-platform products

Maintain:
- brand;
- terminology;
- information architecture;

while adapting:
- controls;
- navigation;
- touch targets;
- keyboard shortcuts;
- gestures;
- typography conventions.

"Pixel identical everywhere" is not inherently good consistency.

## Review

- Does this interaction fight platform expectations?
- Is brand consistency being confused with control sameness?
- Does back/cancel behave naturally?
