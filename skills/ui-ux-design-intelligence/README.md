# Zelyq UI/UX Design Intelligence

A product-design skill inspired by the **design-intelligence architecture** of UI UX Pro Max, rebuilt around Zelyq's senior-engineer philosophy.

The source project is useful because it separates searchable design knowledge into domains such as styles, colors, typography, product types, UX guidelines, motion, charts, icons, landing patterns, and stack-specific guidance. Zelyq's version keeps that modular idea but puts stronger emphasis on:

- product and user reasoning before style;
- information architecture;
- interaction models and recovery;
- evidence-aware UX claims;
- design-system semantics;
- accessibility at design time;
- adaptive/mobile/platform behavior;
- browser visual critique;
- adversarial design evals.

This skill complements `frontend-ui-engineering`: this package decides **what the interface should be and why**; frontend engineering decides **how to implement it correctly**.
