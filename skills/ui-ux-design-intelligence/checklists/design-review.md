# Design Review Checklist

## Task
- [ ] Primary task discoverable
- [ ] Primary action appropriate
- [ ] User can cancel/recover

## Hierarchy
- [ ] One clear starting point
- [ ] Related content grouped
- [ ] Secondary content visually secondary

## Content
- [ ] User language
- [ ] Errors actionable
- [ ] No fake proof/metrics

## Accessibility
- [ ] Contrast
- [ ] Focus
- [ ] Targets
- [ ] Non-drag alternative
- [ ] Reduced motion
- [ ] Large text/reflow

## Adaptation
- [ ] Mobile
- [ ] Wide
- [ ] Long content
- [ ] Localization/RTL where relevant

## Craft
- [ ] Alignment
- [ ] Spacing rhythm
- [ ] Typography hierarchy
- [ ] Color roles
- [ ] Component consistency
