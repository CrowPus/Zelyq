# Design Definition of Done

- [ ] User/product goal is explicit.
- [ ] Top tasks are identified.
- [ ] Information hierarchy is clear.
- [ ] Navigation/IA is coherent.
- [ ] Interaction feedback and recovery are designed.
- [ ] Visual direction has rationale.
- [ ] Semantic color/type/spacing roles exist.
- [ ] Important states are designed.
- [ ] Responsive/adaptive behavior is intentional.
- [ ] Accessibility risks are addressed.
- [ ] Motion has functional purpose.
- [ ] Realistic content has been tested.
- [ ] Rendered design has been inspected where tooling exists.
- [ ] Heuristic review found no unresolved critical issue.
