# Recipe: Dashboard Design

## Step 1: Decisions
List decisions users make from the dashboard.

## Step 2: Signals
Map each decision to required signals.

## Step 3: Hierarchy
Prioritize:
- abnormal/urgent;
- overview;
- trend;
- diagnosis;
- action.

## Step 4: Representation
Choose:
- number;
- table;
- chart;
- status;
- timeline;
based on the question.

## Step 5: Scope
Make filter/time/account scope visible.

## Step 6: Drilldown
Every summary should have a logical path to detail when needed.

## Avoid
- 12 equal KPI cards;
- decorative gauges;
- charts without units/time range;
- hidden filter state;
- using color as the only severity signal.
