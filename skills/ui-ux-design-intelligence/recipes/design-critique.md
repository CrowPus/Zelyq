# Recipe: Design Critique

Critique in this order:

1. **Purpose** — what is this screen trying to achieve?
2. **Hierarchy** — is priority visible?
3. **Information architecture** — are groups/navigation correct?
4. **Interaction** — can users act/recover?
5. **Content** — are labels/copy clear?
6. **Accessibility** — any exclusion?
7. **Responsive/platform** — does context adaptation work?
8. **Visual system** — type/color/spacing/shape consistency?
9. **Craft** — optical details, alignment, rhythm.
10. **Delight** — only after the above works.

Use language like:
- "The primary action competes with..."
- "This grouping implies..."
- "The error state does not explain recovery..."

Avoid:
- "I don't like..."
- "Make it pop..."
- "Feels more modern..."
without diagnosis.
