# Zelyq Complete Replica Engineering

A measured engineering skill for faithfully reproducing existing interfaces.

Core loop:

**observe → capture → measure → implement → render → diff → diagnose → correct → repeat**

The skill separates fidelity into visual, structural, behavioral, and responsive layers. It uses deterministic browser capture, font readiness, browser-resolved geometry/computed styles, asset/crop fingerprints, state matrices, breakpoint discovery, scroll checkpoints, and visual regression.

It does not equate replication with copying proprietary source code. Exact protected code/assets are reused only when the user owns, provides, licenses, or is authorized to reuse them.
