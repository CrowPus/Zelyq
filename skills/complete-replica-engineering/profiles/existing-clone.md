# Profile: Existing Clone Correction

## Do not start over automatically

First:
1. capture current replica;
2. diff against reference;
3. classify biggest deltas;
4. inspect architecture;
5. fix the highest-cascade cause.

## Typical high-leverage corrections
- font loading;
- container width;
- root spacing;
- image crop;
- breakpoints;
- shared component dimensions.

Rewrite only when the implementation architecture itself makes faithful correction impractical.
