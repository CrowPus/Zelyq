# Profile: Animation-Heavy Experience

## Separate two baselines

### Static visual baseline
Animations disabled/settled for layout and paint comparison.

### Motion baseline
Record key phases:
- initial;
- mid-transition when meaningful;
- final;
- scroll checkpoints.

## Match
- trigger;
- duration;
- easing;
- transform path;
- origin;
- sequencing;
- pinning/scroll relationship.

## Reduced motion
Preserve a production-safe reduced-motion variant even if reference did not visibly demonstrate it.
