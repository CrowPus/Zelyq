# Assets and Provenance

## Inventory

For each asset record:
- source/provenance;
- intrinsic size;
- aspect ratio;
- displayed size;
- crop;
- object-fit;
- object-position;
- mask/radius;
- opacity/blend;
- SVG viewBox;
- stroke/fill.

## Rights

Exact protected assets may be used when:
- user supplied them;
- project already contains them;
- user owns/controls them;
- license/authorization permits reuse.

Do not scrape proprietary asset bundles merely to achieve visual exactness when reuse is not authorized.

## Substitution

If exact reuse is not authorized:
- preserve footprint/aspect/crop behavior;
- use permitted substitute;
- mark fidelity limitation.

## Icons

Icon fidelity depends on:
- family;
- viewBox;
- stroke width;
- cap/join;
- fill;
- optical size.

Do not replace a distinctive icon set with generic emoji.
