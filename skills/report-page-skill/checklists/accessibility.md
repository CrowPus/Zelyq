# Report Accessibility Checklist

- [ ] Semantic heading hierarchy
- [ ] Main landmark
- [ ] Tables use captions/headers appropriately
- [ ] Status does not depend on color alone
- [ ] Text/controls meet applicable contrast
- [ ] Visible focus on interactive elements
- [ ] Charts have accessible text/data alternative
- [ ] Reduced motion honored
- [ ] Page reflows/zooms without losing reading flow
- [ ] Table overflow is local, not whole-page
- [ ] Links have meaningful labels
- [ ] Images/diagrams have appropriate alternatives
