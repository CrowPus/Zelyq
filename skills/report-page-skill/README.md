# Zelyq Report Page Design

A specialist skill for transforming completed analysis into a designed web report without changing the analysis itself.

The source prompt's central insight is retained: find the report's **spine** before designing, identify the claim most likely to be misunderstood, match visual language to the subject domain, and preserve exact numbers and conclusions. The source treats the work as "treatment" rather than new analysis; this package expands that with stronger source-fidelity controls, accessible table semantics, chart ethics, evidence/uncertainty treatment, responsive analytical layouts, theme validation, provenance, browser QA, and adversarial evaluations.

This is not a marketing-page skill.
