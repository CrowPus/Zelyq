# Recipe: Find the Report Spine

Read the entire source.

Write:

```yaml
masthead:
  claim:
  metric:
  verdict:

evidence:
  - ...
  - ...

misreading:
  likely_reader_error:
  clarification:

action:
  recommendation:
```

Reject a spine that contains multiple competing masthead metrics.

If the most surprising or misleading finding is buried in the source, surface it without changing its meaning.
