# Recipe: "Read This Correctly" Block

## Use when
A metric or statement looks stronger/weaker than its actual interpretation.

## Structure
1. display the potentially misleading value;
2. label exactly what it measures;
3. contrast with the decisive metric/claim;
4. explain the distinction in one or two sentences.

Do not use dramatic styling that makes the caveat look like a separate new finding.

The purpose is interpretation, not spectacle.
