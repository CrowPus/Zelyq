# Responsive Analytical Layout

Report layouts should preserve reading and comparison under narrow viewports and zoom.

## Prose
Use readable measure and comfortable line height.

## Tables
Prefer semantic tables with local horizontal overflow rather than transforming comparison data into unrelated cards.

For very complex tables:
- split by logical group;
- freeze/retain important context where implementation permits;
- keep captions/headers understandable.

## Charts
Ensure labels remain readable and provide text/table alternatives.

## Mobile hierarchy
Preserve:
- verdict;
- main evidence;
- caveat;
- recommendation.

Reduce decoration before reducing essential information.

## Wide screens
Do not stretch prose indefinitely. Let data blocks exceed prose measure when comparison needs width.
