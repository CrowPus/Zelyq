# Evidence and Uncertainty

Distinguish:
- confirmed;
- measured;
- estimated;
- inferred;
- hypothesis;
- unavailable.

Do not let layout erase epistemic differences.

If the source provides confidence, preserve the exact level/interval and what it refers to.

A caveat that materially changes interpretation belongs near the affected claim.

Missing data should be explicit:
- Not measured
- Not available
- Insufficient sample
- Out of scope

Never substitute zero.

When evidence conflicts, show evidence for, evidence against, and unresolved question. Do not average incompatible findings into a clean-looking score unless the source methodology does so.
