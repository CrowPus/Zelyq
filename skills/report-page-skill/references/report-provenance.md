# Report Provenance

Reports may be shared as screenshots, exports, or detached links, so context can disappear.

Where appropriate include:
- title;
- date;
- source/author;
- organization/team;
- analysis period;
- methodology;
- version;
- scope;
- data source;
- draft/final status.

Include enough methodology to interpret results, but do not imply rigor not present in the source.

If regenerated:
- update version/date;
- preserve stable report identity when appropriate;
- avoid silently replacing historical reports when auditability matters.

Do not expose confidential authorship/scope metadata to audiences that should not see it.
