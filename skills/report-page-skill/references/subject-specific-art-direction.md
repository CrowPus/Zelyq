# Subject-Specific Art Direction

The page should look like it belongs to the report's professional domain.

Ask:
> What does authoritative information look like in this field?

Examples:

## Audit / compliance
Use institutional-document, ledger, controls, evidence-register language. Keep severity restrained.

## Security assessment
Use technical-report, evidence, status, code/data notation. Avoid decorative "cyber" clichés unless subject requires them.

## Incident postmortem
Use timeline, operational timestamps, event markers, root-cause structure, recovery status.

## Benchmark / evaluation
Use lab/report notation, comparison, tabular numerals, measurement axes, threshold markers.

## Strategy / committee
Use executive memo, evidence hierarchy, recommendation, institutional typography.

## Architecture / code review
Use diagrams, code/editor notation, structural rules, technical annotation.

Genericity test:
Would the same exact direction work unchanged for an unrelated wedding site, crypto landing page, and security audit? If yes, revise.

A restrained neutral system is valid when it fits the field.
