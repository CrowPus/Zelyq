# Recommendations and Decisions

A report should make the next decision understandable.

Structure:
- recommendation;
- owner/audience;
- priority;
- prerequisite;
- evidence/rationale;
- timing if source provides it.

Do not invent roadmap or implementation steps not present in the source unless asked.

When options compete:
- preserve selection criteria;
- show tradeoffs;
- identify chosen/rejected;
- preserve uncertainty.

If decision is the purpose of the report, give it a strong final section rather than burying it in a footer.
