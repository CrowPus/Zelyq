# Data Visualization for Reports

Start with the analytical question.

Use:
- line for trend;
- bar for category comparison;
- scatter for relationship;
- histogram/box plot for distribution;
- table for exact values;
- stacked bar for simple composition;
- timeline for ordered events.

Do not choose chart type for spectacle.

Avoid misleading:
- truncated bar axes that exaggerate differences;
- inconsistent scales across small multiples;
- area/volume encodings for precise comparison;
- 3D effects that distort magnitude.

Show units, period, baseline, sample size when material, source, and target/threshold.

Prefer direct labels when they reduce legend lookup.

Important chart information needs text/table alternatives and must not rely only on hue.

If there are only a few exact values, a table or labeled bars may be clearer than a full chart.
