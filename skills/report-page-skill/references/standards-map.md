# Standards and Research Map

## Source prompt
The provided `report-page` prompt contributes several valuable design principles:
- read the entire source before styling;
- identify one report "spine";
- surface the likely misreading/caveat;
- match structure to actual analytical structure;
- derive visual language from the subject's professional world;
- preserve load-bearing numbers and conclusions;
- treat severity colors separately from general accent.

Zelyq's version generalizes those ideas and adds stronger source fidelity, accessibility, visual-evidence rules, provenance, responsive design, and automated QA.

## Interpretation

Use these sources as guidance for:
- semantic/accessible structure;
- comparison;
- reading hierarchy;
- information organization;
- theme/token design.

Do not treat visual conventions such as "65ch" or a specific palette as normative standards.
