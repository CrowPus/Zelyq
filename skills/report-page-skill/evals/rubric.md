# Report Page Evaluation Rubric

Score 0–5.

1. **Source fidelity** — numbers, verdict, caveats, uncertainty, attribution preserved.
2. **Report spine** — one clear conclusion with evidence and action.
3. **Information architecture** — structure matches analytical content.
4. **Interpretation quality** — likely misreading/caveat is surfaced.
5. **Representation judgment** — prose/table/chart/callout chosen appropriately.
6. **Visual direction** — subject-specific, credible, non-generic.
7. **Data integrity** — scales, thresholds, rankings, units are honest.
8. **Accessibility** — semantic tables, non-color meaning, contrast, focus, chart alternatives.
9. **Responsive/theming quality** — narrow layout and system/light/dark states work where applicable.
10. **Editorial craft** — hierarchy, typography, spacing, numeric alignment, restraint.

## Critical failures

Automatic fail if:
- any load-bearing number, unit, threshold, ranking, quote, or verdict is changed incorrectly;
- evidence uncertainty is upgraded to certainty;
- fake data/chart/testimonial/source is invented;
- a decisive caveat is hidden so the page becomes misleading;
- a comparison table is transformed so comparison meaning is lost;
- a chart materially distorts the source data;
- status meaning relies only on color;
- theme implementation makes text unreadable in a valid theme state;
- report is treated as a marketing landing page and the analytical spine is obscured.

## Passing target

- total ≥ 40/50
- no critical failure
- source fidelity and data integrity each ≥ 4
- accessibility ≥ 3

High-quality publication target: 45+/50.
