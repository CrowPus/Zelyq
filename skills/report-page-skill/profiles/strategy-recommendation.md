# Profile: Strategy / Committee / Recommendation

## Reader need
Understand choice, criteria, tradeoffs, recommendation, and next action.

## Structure
1. recommendation/verdict;
2. decision criteria;
3. evidence;
4. option comparison;
5. risks/caveats;
6. action.

## Visual language
Executive memo / analytical publication.

## Comparison
Use matrices/tables when options share criteria.

## Avoid
- marketing-style persuasion;
- hiding rejected alternatives;
- inventing implementation roadmap not in source.
