# Profile: Audit / Security / Compliance

## Reader need
Understand risk, evidence, affected scope, status, and remediation.

## Structure
Possible:
1. executive verdict;
2. scope/method;
3. finding summary;
4. findings by severity/system;
5. caveats/limitations;
6. remediation priorities.

## Visual language
Use restrained institutional/technical treatment.

Semantic severity colors are reserved for severity.

## Finding anatomy
For each finding preserve:
- title;
- severity;
- evidence;
- scope;
- impact;
- status;
- remediation.

Do not collapse severity and remediation status.

## Avoid
- "hacker" visuals;
- neon cyber decoration;
- every finding inside dramatic red card;
- charts where a table is clearer.
