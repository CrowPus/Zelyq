# Profile: Incident / Postmortem

## Reader need
Understand what happened, impact, timing, causes, recovery, and prevention.

## Structure
1. incident summary;
2. impact;
3. timeline;
4. root cause;
5. contributing factors;
6. recovery;
7. corrective/preventive actions.

## Time
Preserve timezone and source precision.

## Causality
Distinguish:
- observed event;
- suspected cause;
- confirmed root cause.

## Visual language
Operational, timestamp-led, calm.

Red should communicate actual critical states, not general decoration.

## Avoid
- blame-oriented treatment;
- decorative timeline steps detached from timestamps;
- hiding uncertainty around root cause.
