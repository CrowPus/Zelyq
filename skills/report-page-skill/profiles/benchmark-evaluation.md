# Profile: Benchmark / Evaluation

## Reader need
Compare systems, understand methodology, thresholds, and why one result wins.

## Structure
1. evaluation question;
2. key result;
3. methodology;
4. comparison table/chart;
5. outliers;
6. limitations;
7. conclusion.

## Visual language
Lab/report notation, strong numeric alignment, restrained data hue.

## Preserve
- scale;
- units;
- sample size;
- methodology;
- uncertainty.

## Avoid
- radar charts for ordinary comparison;
- unequal axes;
- rounding that changes ranking;
- decorative trophy treatment unsupported by methodology.
