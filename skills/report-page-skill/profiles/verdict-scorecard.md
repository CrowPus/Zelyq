# Profile: Verdict / Scorecard

## Reader need
Understand the decision quickly, then inspect the evidence and thresholds.

## Recommended spine
1. verdict;
2. primary score/claim;
3. scorecard/evidence;
4. misleading outlier/caveat;
5. thresholds;
6. recommendation.

## Visual emphasis
Use one dominant verdict/metric.

Do not make every subscore equally prominent.

## Thresholds
Make threshold semantics explicit:
- actual;
- threshold;
- pass/fail interpretation.

## Good patterns
- score bar + exact number;
- comparison table;
- threshold matrix;
- "read this correctly" explanation.

## Avoid
- gauge dashboard;
- six hero numbers;
- verdict hidden below fold;
- decorative rank numbering.
