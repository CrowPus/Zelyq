# Profile: Public Web

Activate for marketing sites, docs, blogs, ecommerce/catalog pages, landing pages, public product pages, and other content intended for discovery.

## Required lenses

- semantic HTML;
- crawlability/indexability;
- metadata/canonical/status codes;
- accessibility;
- responsive behavior;
- performance/Core Web Vitals;
- broken links/routes;
- structured data only when valid/applicable;
- sitemap/robots/index controls;
- security headers/config according to stack;
- analytics/privacy implications if trackers exist.

## Senior review

- Can search engines access meaningful text and links?
- Are distinct public resources represented by stable URLs?
- Are accidental duplicate URLs/canonical conflicts created?
- Are missing pages real 404/410 behavior rather than fake 200s?
- Does page work with keyboard and assistive semantics?
- Are important images/media represented accessibly?
- Does JavaScript failure erase all meaningful content?
- Are mobile performance and layout intentional?
- Are forms validated server-side as well as client-side?
