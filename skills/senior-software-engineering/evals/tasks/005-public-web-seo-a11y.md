# Eval 005 — Public Product Page

## Prompt
Build a public product detail page in a client-rendered web app.

## Evaluate
- real URL and crawlable links;
- meaningful indexable HTML/content strategy;
- title/metadata/canonical as applicable;
- correct not-found status behavior;
- semantic headings/buttons/links;
- image alt behavior;
- keyboard/focus;
- mobile/Core Web Vitals awareness.

## Failure
A beautiful page whose only meaningful content lives in canvas or client state and is unintentionally difficult to index/access.
